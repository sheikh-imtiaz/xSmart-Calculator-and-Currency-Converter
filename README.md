# xSmart-Calculator-and-Currency-Converter
CalcX – Smart Calculator &amp; Currency Converter


The project will use React, Vite, Tailwind-style custom CSS, Lucide icons, localStorage, and the free Frankfurter exchange-rate API. 
Frankfurter provides regularly updated reference exchange rates, rather than second-by-second trading prices.

The application will include a general calculator, currency converter, calculation and conversion history, dark/light mode, responsive design, keyboard support, and error handling.

How to run it on computer
Need Node.js and an editor such as VS Code.
1. Extract the ZIP.
2. Open the calcx folder in VS Code.
3. Open the integrated terminal.
4. Run these commands:

npm install
npm run dev

5. Open the local address shown in your terminal, usually http://localhost:5173.
To run the tests and generate a production build:
npm test
npm run build


**xSmart Calculator & Currency Converter**

Developed a responsive React.js application combining a general-purpose calculator and a currency converter powered by an external exchange-rate API.

- Built reusable React components with Hooks and JavaScript.
- Integrated the Frankfurter REST API for currency conversion.
- Implemented localStorage-based history and persistent theme preferences.
- Added keyboard interactions, input validation, and API error handling.
- Configured the application for automated deployment using Vercel or Netlify.

**Technologies:** React.js, JavaScript, Vite, CSS, REST API, Git, Vitest.
